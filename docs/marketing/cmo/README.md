# CMO living files

The working memory of Lyceon's CMO (the `cmo` skill in `.claude/skills/cmo/`). Every CMO run reads these files first and writes back what changed. See `.claude/skills/cmo/references/07-team-and-operations.md` §6 for what each file holds.

This repo is public: nothing proprietary, no student data, no personal emails. While the repo is public, reports, metrics, decision memos and internal account IDs are not committed here; the CMO saves them to Karl's Google Drive (folder: CMO reports) (Karl, 2026-10-15).

Notebook lane (thread, research notes, ideas, gate status, words only) merges through docs-only PRs without Karl's review. Decision lane (actions/) needs Karl's merge.
