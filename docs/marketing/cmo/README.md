# CMO living files

The working memory of Lyceon's CMO (the `cmo` skill in `.claude/skills/cmo/`). Every CMO run reads these files first and writes back what changed. See `.claude/skills/cmo/references/07-team-and-operations.md` §6 for what each file holds.

This repo is public: nothing proprietary, no student data, no personal emails. Internal accounts are listed by ID only. Everything here is aggregate.

Notebook lane (thread, reports, research, ideas, snapshots) merges through docs-only PRs without Karl's review. Decision lane (memos/, actions/) needs Karl's merge.
