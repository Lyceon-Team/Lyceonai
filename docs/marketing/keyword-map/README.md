# SAT keyword map

**What it is:** the SAT keyword → target-page map for the SEO & Marketing vertical
(`lyceon-sat-keyword-map.xlsx`).

**Source:** Google Ads Keyword Planner — United States, English, last 12 months, exported
2026-10-02. The raw exports are in `source/` (UTF-16LE, committed byte-identical; see
`.gitattributes`).

**Rules:**

- Search volumes are Google's buckets, not measurements. Never sum them.
- The README sheet inside the xlsx documents the method.
- This map is an internal working file — not linked from the product.

**Plan:** the vertical plan is `docs/plans/seo/seo-marketing-vertical.md`.
